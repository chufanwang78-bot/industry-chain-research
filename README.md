## 启动

```bash
cd ~/industry-chain-research
python3 app.py
```

浏览器打开 **http://localhost:5000**

---

## 产业框架（四视角）

| 视角 | 回答什么 | 编号 |
|------|---------|------|
| 📌 产品视角 | 芯片有哪些品类、各有什么特点 | 01-09 |
| ⚙️ 制造过程 | 芯片怎么做出来的、每道工序 | 10-19 |
| 🧪 材料视角 | 用什么材料、谁在做、国产化 | 20-29 |
| 🔧 设备视角 | 用什么设备、谁在做 | 30-39 |
| ⭐ 机会汇总 | 安徽企业、新闻、合作切入点 | 90-99 |

**最终产出**：企业清单 + 新闻动态 + 产研院合作机会

---

## 研究流程（参考屏幕产业链拆解方法）

```
产品拆解 → 找企业 → 筛安徽/长三角 → 搜新闻 → 记录机会
```

每个节点的填写要点：
1. 这是什么 / 功能
2. 分类与技术路线
3. 代表企业（重点：安徽/长三角）
4. 技术难点与需求
5. **⭐ 新闻/事件追踪**（核心产出）
6. **⭐ 产研院合作切入点**
7. 来源与证据

## 命令行工具

```bash
python3 ic_tools.py status    # 进度
python3 ic_tools.py tree      # 树状图
python3 ic_tools.py next      # 待研究
python3 ic_tools.py report    # 报告
python3 ic_tools.py check     # 质检
python3 ic_tools.py log "内容" # 日志
```

## 研究顺序建议

1. 先跑**材料视角**（光刻胶、硅片、特气）—— 材料事业部主战场
2. 再跑**制造过程**（拉晶→封装完整流程）—— 理解产业全貌
3. 补**设备视角**—— 国产化热点
4. 按需深入**产品视角**—— 各品类特点
5. 持续更新**机会汇总**—— 新闻+合作机会

## 迁移到新产业

1. 修改 `config/workflow.yaml`
2. `python3 ic_tools.py init --force`
3. 开始研究
