# 资料来源记录模板

> 用于 `sources/source-index.yaml` 中的每条记录格式说明
> 每条来源必须有可访问的路径或 URL

## 来源字段说明

```yaml
- id: S001                    # 来源编号（全局递增）
  title: "来源标题"            # 文章/报告/网页标题
  type: "网页/论文/报告/官网/新闻/视频/访谈/其他"
  url: "https://..."          # 可访问的 URL 或文件路径
  publisher: "发布机构"        # 媒体/机构名称
  publish_date: "2025-01"     # 发布日期（如已知）
  access_date: "2025-10-15"   # 我们访问/查阅的日期
  related_nodes: ["01.01"]    # 关联的节点编号
  evidence_level: "CONFIRMED" # CONFIRMED / INFERRED / UNVERIFIED / DOUBTFUL
  summary: "证据摘要"          # 该来源支持什么事实，1-3句话
  notes: "备注"               # 可靠性说明、局限性等
```

## 证据等级判断标准

- **CONFIRMED**: 来源可访问、内容明确、来源可靠（官方网站、权威媒体、学术论文、政府文件）
- **INFERRED**: 基于多个 CONFIRMED 来源的逻辑推断，非直接陈述
- **UNVERIFIED**: 信息可能正确但来源不够权威或无法完全确认
- **DOUBTFUL**: 来源可靠性存疑，仅供参考

## 来源质量要求

1. 企业信息：至少需要企业官网 + 一个第三方平台（企查查/天眼查/行业数据库）
2. 技术参数：优先采用规格书/论文，其次权威评测，标注来源类型
3. 市场数据：注明来源机构和统计口径
4. 产业链关系：注明来源是官方公告、行业报告还是推断
